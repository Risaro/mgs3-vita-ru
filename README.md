# Metal Gear Solid 3 HD для PS Vita: русификатор

Инструменты для переноса русского перевода ПК-версии MGS3 (Master Collection) на PS Vita
и исходники плагина taiHEN, который подключает русский шрифт и переводит меню.

Перевод: **Mr.President** (t.me/mgs3ru)
Порт на PS Vita: **Risaro** (t.me/lik1sa)

Игра: Metal Gear Solid 3 HD, европейская версия `PCSB00176`, 01.00.
Это отдельная игра, не HD Collection.

## Что переводится

- субтитры катсцен, роликов и реплик (`us/demo`, `us/movie`, `us/vox`, `.sdt`)
- радио и карточки персонажей (`fr/codec`, `.sdt`)
- подсказки, описания предметов, системные сообщения (`assets/gcx/fr`, `.gcx`)
- текстуры с текстом и логотип (`textures/flatlist`, `.ctxr`)
- шрифтовые атласы меню (кириллица на месте третьего ряда)
- строки меню в `eboot.bin` (через плагин)

Подробный разбор памяти игры и того, как шла работа: [Карта памяти и заметки](#карта-памяти-и-заметки).

## Как устроено

**Архив.** Игра читает один архив `mgs3_eu.psp2arc` (PSARC, zlib, блоки по 64 КБ).
rePatch подменяет его целиком, поэтому `build_all.py` пересобирает архив,
заменяя только переведённые файлы. Без изменений пересборка совпадает с оригиналом байт в байт.

**Субтитры `.sdt`.** Чанк `PACB` нельзя менять в размере: игра зависает на загрузке катсцены.
Русский текст ставится на место английского (lang 1), тексты других языков укорачиваются,
чтобы тело чанка осталось ровно исходного размера.

**Кодек и `.gcx`.** Блок LCGB содержит две таблицы строк: основную (UTF-8) и служебную
(старая кодировка PS2). В кодеке основная таблица переводится, служебная генерируется заново
(латиница с диакритикой по таблице из оригинальных файлов, кириллица транслитом).
В `.gcx` служебная секция копируется без изменений. Текст ПК-версии местами в cp1251,
он перекодируется в UTF-8.

**Текстуры `.ctxr`.** Заголовок 32 байта, 8-битные индексы (pitch кратен 8, область пикселей
выровнена до 64 байт), палитра 256 x RGBA в последних 1024 байтах, альфа 0..128.
Текстуры со сторонами степени двойки хранятся в порядке Morton (сначала бит Y).

**Плагин** `mgs3ru.suprx`:
- перехватывает загрузчик шрифта игры и подставляет шрифт с кириллицей;
- подменяет строки меню однобайтовой кодировкой из `tools/cyrmap.py`;
- перенаправляет указатели на подсказки внизу экрана на русские строки в UTF-8.

## Сборка

Нужны Python 3 с `numpy` и `Pillow`, VitaSDK и:

1. `dump/dec/mgs3_eu.psp2arc`: расшифрованный архив игры (VitaShell, Open decrypted).
2. `dump/elf/eboot.bin.elf`: расшифрованный `eboot.bin` (FAGDec, режим ELF).
3. `pc-rus/x/`: распакованный русификатор Mr.President для ПК.
4. `pc-rus/font/font.bin`: шрифт русификатора, `gzip -dc < pc-rus/x/Font_Mr.President > pc-rus/font/font.bin`.

Архив:

```
python3 tools/build_all.py
```

Результат: `out/rePatch/PCSB00176/mgs3_eu.psp2arc`.
Можно собрать часть: `--only=demo,movie,vox,codec,gcx,textures`.

Плагин (VitaSDK в `tools/ext/vitasdk` или через переменную `VITASDK`):

```
tools/plugin/make.sh
```

Результат: `tools/plugin/mgs3ru.suprx`.

## Установка

1. `rePatch/PCSB00176/mgs3_eu.psp2arc` в `ux0:rePatch/PCSB00176/`
2. `mgs3ru.suprx` в `ur0:tai/`
3. В `ur0:tai/config.txt`:
   ```
   *PCSB00176
   ur0:tai/mgs3ru.suprx
   ```
4. Перезагрузить консоль.

Плагин обязателен: без него вместо русского текста будут пустые полосы.

Файлы игры и русификатора в репозиторий не входят.

## Карта памяти и заметки

### Сегменты `eboot.bin`

Это `ET_SCE_EXEC`, загружается по фиксированным адресам, без релокаций.

| Сегмент | Адрес | Смещение в файле | Размер в файле / в памяти | Права | Что внутри |
|---|---|---|---|---|---|
| 0 | `0x81000000` | `0x1000` | `0x99DD88` / `0x99DD94` | R X | код и константы, в том числе строки меню |
| 1 | `0x8199E000` | `0x99F000` | `0x3466EC` / `0x167BC60` | R W | данные, таблицы ширин, указатели на строки, BSS |

Перевод адреса в смещение в ELF: сегмент 0 `адрес - 0x81000000 + 0x1000`,
сегмент 1 `адрес - 0x8199E000 + 0x99F000`. Плагин на всякий случай считает
поправку от реальных адресов сегментов (`sceKernelGetModuleInfo`), на консоли она нулевая.

### Важные адреса

| Адрес | Сегмент | Назначение |
|---|---|---|
| `0x81681DF0` | 0 | загрузчик основного шрифта, сюда ставится хук |
| `0x818ADBC4` | 0 | malloc игры, через него плагин выделяет память под шрифт |
| `0x81B17E7C` | 1 (BSS) | состояние шрифта, `3` значит загружен |
| `0x81B17E80` | 1 (BSS) | указатель на данные шрифта |
| `0x81960000..0x81990000` | 0 | область строк меню (файл `0x960000..0x990000`) |
| `0x819EE4F0`, `0x819EE550` | 1 | таблицы ширин шрифта меню 12 px (выбор по флагу) |
| `0x819EE5B0`, `0x819EE610` | 1 | таблицы ширин пиксельного шрифта 8 px (выбор по флагу) |
| `0x819EE670` | 1 | таблица ширин моноширинного шрифта, все по 8 |
| `0x82313C20` | 1 (BSS) | флаг, по которому выбирается одна таблица из пары |
| `0x8109A59C` | 0 | инициализация шрифтов меню, сохраняет указатели на таблицы ширин |
| `0x8109A578` | 0 | функция выбора таблицы ширин 8 px по флагу |
| `0x8160E274..0x8160E5A0` | 0 | отрисовка строки: ширина символа `table[c - 0x20]` |
| `0x8109BB12`, `0x8109B2D4` | 0 | ещё два места отрисовки с тем же чтением ширины |

Таблица ширин занимает 96 байт, по байту на символ от `0x20` до `0x7F`.
Атлас шрифта меню содержит 32 x 3 ячейки, номер ячейки равен `код - 0x20`.
При отрисовке ширина задаёт сразу и сдвиг курсора, и ширину вырезаемого из атласа куска.
Поэтому глиф шире своей ширины обрезается справа, а следующий символ налезает на предыдущий.

### Как плагин пишет в память

- **Сегмент 0** (код, только чтение): строки меню подменяются через `taiInjectData(modid, 0, смещение, ...)`.
  Прямая запись в этот сегмент невозможна.
- **Сегмент 1** (данные): указатели на подсказки и указатель на шрифт пишутся напрямую
  внутри хука загрузчика шрифта, когда игра уже инициализирована.
- Прямая запись в сегмент 1 из `module_start` в первых версиях приводила к вылету при запуске,
  поэтому всё перенесено в хук.

### Кодировка меню

Шрифт меню однобайтовый, в атласе есть место только под коды `0x20..0x7F`.
Кириллица размещена так (см. `tools/cyrmap.py`):

- А В Е К М Н О Р С Т Х пишутся латинскими кодами, З пишется цифрой `3`;
- остальные 20 букв стоят в третьем ряду атласа на кодах, у которых родная ширина
  подходит во всех четырёх таблицах (`` ` a b c d e g h o p q s u v w x y z { ~ ``).

Коды `i j k l m n r t f | }` и `0x7F` не используются: у них в оригинальных таблицах
маленькая ширина (4..8), и буквы на них налезали друг на друга.

### Почему не патч ширин

Первая версия ставила кириллицу подряд на `0x60..0x7F` и правила таблицы ширин.
На консоли это не сработало: буквы на месте `k l m n` (Л М Н О) и других узких кодов
продолжали налезать. Проверено:

1. запись таблиц в хуке шрифта;
2. перезапись таблиц каждые 0,5 с из отдельного потока;
3. `taiInjectData` в сегмент 1 при старте;
4. контрольная сборка с шириной 20 для всех заглавных букв.

Диагностика, выведенная прямо в пункт меню, показала, что сегмент 1 начинается с `0x8199E000`,
байт таблицы после записи меняется (`0B` на `14`) и ошибок нет. Но отрисовка всё равно
использует оригинальные значения. Копий таблиц в `eboot.bin` и в архивах нет ни подряд, ни с шагом.
Видимо, игра где-то держит свою копию ширин, которая собирается во время работы.
Раскладка из `cyrmap.py` от этого не зависит, поэтому выбрана она.

### Что ломало игру по ходу работы

| Симптом | Причина | Решение |
|---|---|---|
| пересобранный архив без изменений отличался от оригинала | у файлов нулевого размера нет блока | для них пишется пустой блок |
| вылет на загрузке катсцены | `.sdt` стал больше исходного | `exact_sdt` сохраняет размер чанка `PACB` |
| чёрный экран вместо катсцены | пустые строки и хвост нулей в `.sdt` | тексты других языков укорачиваются, а не удаляются |
| вылет сразу при запуске с плагином | запись в сегмент 1 из `module_start` | запись перенесена в хук загрузчика шрифта |
| сдвинутые картинки | неверный заголовок `.ctxr` (считали 64 байта) | заголовок 32 байта, палитра в конце, Morton |
| `.gcx` пересобирался не байт в байт | в служебной секции есть данные без ссылок | служебная секция копируется целиком |
| буквы меню налезали и обрезались | ширины кодов `0x60..0x7F` не подходят для кириллицы | раскладка `cyrmap.py` |
